# 🍽️ Zomato Restaurant Data Analysis & Insights Dashboard

## 📊 Project Overview
This project analyzes restaurant data from Zomato to uncover insights about restaurant popularity, customer ratings, online ordering trends, table booking availability, and cost patterns.

The analysis was performed using Python for data cleaning and exploratory data analysis (EDA) and Power BI for building an interactive dashboard.

The main goal of this project is to convert raw restaurant data into meaningful insights that help understand customer preferences and restaurant performance.

---

# 🎯 Project Objectives

- Identify the most popular restaurant types
- Analyze restaurant ratings and votes
- Understand the impact of online ordering on ratings
- Examine table booking availability
- Compare cost trends across restaurant categories
- Highlight top restaurants based on customer votes

# ⚙️ Project Workflow

## 1️⃣ Data Collection
The dataset was downloaded from an online source containing information about restaurants listed on Zomato.

## 2️⃣ Data Cleaning (Python)
The dataset was cleaned using Python to prepare it for analysis.

Cleaning steps included:
- Handling missing values
- Removing duplicate records
- Standardizing column names
- Converting data types
- Preparing structured data for analysis

## 3️⃣ Exploratory Data Analysis (Python)
Exploratory analysis was performed using Python libraries to understand patterns and trends in the dataset.

Analysis included:
- Restaurant type distribution
- Votes comparison
- Rating analysis
- Cost analysis

## 4️⃣ Dashboard Development (Power BI)
After cleaning the dataset, it was loaded into Power BI to build an interactive dashboard.

The dashboard allows users to explore:
- Restaurant popularity
- Online ordering trends
- Table booking availability
- Cost comparisons
- Top restaurants based on votes
